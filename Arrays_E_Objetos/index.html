Arrays e Objetos em JavaScript

O que são Arrays?

Arrays são estruturas utilizadas para armazenar vários valores dentro de uma única variável.

Eles permitem organizar listas de informações, como nomes, números, produtos ou qualquer outro tipo de dado.

Exemplo de Array


let frutas = [

    "Maçã",

    "Banana",

    "Laranja"

];

Nesse exemplo, o array chamado frutas armazena três valores diferentes.

O que são Objetos?

Objetos são estruturas que armazenam informações em pares de chave e valor.

Eles são muito utilizados para representar entidades do mundo real, como pessoas, produtos e veículos.

Exemplo de Objeto


let aluno = {

    nome: "Murilo",

    idade: 17,

    curso: "Desenvolvimento Web"

};

O objeto acima possui três propriedades: nome, idade e curso.

Exemplo Prático

Clique no botão para visualizar informações armazenadas em um objeto e em um array.

Arrays e Objetos Juntos

Em aplicações web, é muito comum utilizar arrays contendo vários objetos. 


let alunos = [

    { nome: "Ana" },

    { nome: "Carlos" },

    { nome: "João" }

];

Essa estrutura é muito utilizada para armazenar e manipular grandes quantidades de dados.
