Manipulação do DOM e Eventos

O que é DOM?

DOM significa Document Object Model (Modelo de Objeto do Documento). Ele representa toda a estrutura de uma página HTML em forma de objetos, permitindo que o JavaScript acesse, modifique e interaja com os elementos da página.

Através do DOM, é possível alterar textos, cores, imagens, adicionar elementos, remover conteúdos e criar interações dinâmicas.

O que são Eventos?

Eventos são ações que acontecem na página e podem ser detectadas pelo JavaScript.

Alguns exemplos são:

  • Clique em um botão (click)
  • Movimento do mouse (mouseover)
  • Digitação em campos (keyup)
  • Envio de formulários (submit)

Os eventos tornam as páginas web interativas e permitem responder às ações dos usuários em tempo real.

Exemplo de Código


const texto = document.getElementById("mensagem");

function alterarTexto() {

    texto.innerText = "Texto alterado com JavaScript!";

}

Nesse exemplo, o JavaScript acessa um elemento HTML através do seu ID e altera o texto exibido na página.
