Funções em JavaScript

O que são Funções?

Funções são blocos de código criados para executar uma tarefa específica. Elas permitem reutilizar código, tornando os programas mais organizados e fáceis de manter.

Sempre que uma função é chamada, as instruções definidas dentro dela são executadas.

Por que utilizar Funções?

Em aplicações web, diversas tarefas precisam ser executadas várias vezes, como validar formulários, calcular valores ou exibir mensagens.

Utilizando funções, evitamos repetir código e deixamos o desenvolvimento mais eficiente.

Exemplo de Função

O exemplo abaixo cria uma função chamada saudacao(). 


function saudacao() {

    alert("Olá, mundo!");

}

Quando a função for chamada, uma mensagem será exibida para o usuário.

Funções com Parâmetros

As funções também podem receber informações chamadas parâmetros. 


function saudar(nome) {

    alert("Olá, " + nome);

}

Nesse caso, o valor enviado para o parâmetro nome será utilizado dentro da função.
